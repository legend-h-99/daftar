# سجل أنشطة المعالجة وقائمة المعالجين

**الحالة:** مسودة للاعتماد · **آخر مراجعة:** 2026-11-15 · **المالك:** المؤسس

هذا السجل يجمع: (أ) أنشطة المعالجة، و(ب) قائمة المعالجين الخارجيين. كل بند يذكر مصدره في الكود حتى يمكن التحقق منه.
يبقى بعض المعلومات بين أقواس مربعة حتى يُتحقق منها في لوحات المزودين (انظر القسم 4).

## ب) قائمة المعالجين

| المعالج | الدور | البيانات التي يعالجها | موقع المعالجة | عقد المعالجة (DPA) |
|---|---|---|---|---|

## ج) نقاط مفتوحة قبل الاعتماد

1. منطقة قاعدة البيانات الفعلية، وهل يسمح التنظيم بحفظ بيانات الفواتير خارج المملكة (انظر تقرير الامتثال).
2. مدة الاحتفاظ بسجلات النشاط والنسخ الاحتياطية.
3. توقيع عقود المعالجة مع كل مزود أعلاه، والاحتفاظ بنسخها.
4. تعيين مسؤول لحماية البيانات، وهل يُلزم النظام بذلك.

## د) التحقق من الأرقام التي بين أقواس

- **Supabase:** لوحة المشروع ← Project Settings ← Region.
- **Sentry:** لوحة المشروع ← Settings ← Data Scrubbing، وتحقق من إعداد `sendDefaultPii`.
- **Resend وAuthentica:** صفحات الإعداد والعقود في لوحاتهما.
