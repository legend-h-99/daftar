# تفعيل الدخول برقم الجوال

الواجهة والخادم يدعمان رمز تحقق عبر Supabase Auth. لا يظهر خيار الجوال في
صفحة الدخول حتى يُفعّل متغير الواجهة `NEXT_PUBLIC_PHONE_LOGIN_ENABLED=true`.

## إعداد SMS

1. افتح مشروع `daftar` في Supabase ثم **Authentication → Sign In / Providers → Phone**.
2. اختر مزود SMS، وأدخل بيانات حساب المزود السرية في إعدادات Supabase. لا تضعها
   في GitHub أو Cloudflare Pages أو أي متغير يبدأ بـ `NEXT_PUBLIC_`.
3. فعّل Phone provider وتأكيد رقم الهاتف، واضبط رمزًا من 6 أرقام بصلاحية قصيرة.
4. انشر نسخة واجهة جديدة بعد ضبط `NEXT_PUBLIC_PHONE_LOGIN_ENABLED=true` في
   إعدادات بناء Cloudflare Pages.
5. اختبر الإرسال والتحقق برقم مخصص للاختبار قبل إتاحة الدخول للجميع.

تطلب واجهة API رقمًا سعوديًا صالحًا بصيغة `+9665xxxxxxxx`. حد الإرسال الافتراضي
100 رسالة يوميًا على مستوى التطبيق، إضافة إلى حد 3 طلبات في الدقيقة لكل رقم
وعنوان IP، وحد التحقق الحالي 10 طلبات في الدقيقة. يمكن ضبط الحد اليومي من
سرّ Edge Function باسم `SMS_DAILY_SEND_CAP`.

لا يرجع الخادم رمز التحقق إلى المتصفح ولا يقبل رموزًا تجريبية في الإنتاج. عند
غياب إعداد مزود SMS، يُرجع الخادم حالة عدم التوفر ويظل خيار الدخول مخفيًا.
