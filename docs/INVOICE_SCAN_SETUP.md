# تفعيل قراءة فواتير الشراء بالذكاء الاصطناعي

صاحب المشروع يصوّر فاتورة المورد، فيقرأها نموذج رؤية من Claude (Anthropic) ويرجع
مسودة شراء: المورد والتاريخ والأصناف والكميات وسعر الوحدة، مع درجة ثقة لكل سطر.
لا يُحفظ شيء إلا بعد مراجعة المستخدم وضغطه «حفظ»، والشراء يُسجَّل بمصدر `OCR`.
الصورة لا تُخزَّن في دفتر.

المسح متوقف افتراضيًا. يظهر زر التصوير في الويب مع
`NEXT_PUBLIC_SCAN_ENABLED=true`، ولا يقبل الخادم الطلب إلا مع
`SCAN_ENABLED=true` **و** `ANTHROPIC_API_KEY`. بدونهما يرد `POST /purchases/scan` بـ 501
وتعرض الصفحة دليل الإدخال اليدوي.

## 1. مفتاح Anthropic

1. أنشئ مفتاح API من https://console.anthropic.com (يُفضَّل مفتاح خاص بدفتر في
   Workspace مستقل، مع حد إنفاق شهري من لوحة Anthropic).
2. هذا مفتاح سري: لا تضعه في GitHub أو Cloudflare Pages أو أي متغير يبدأ بـ `NEXT_PUBLIC_`.

## 2. الهجرة

طبّق `supabase/migrations/20261117180000_invoice_scan_quota.sql`. تنشئ جدول
`InvoiceScanUsage` والدالتين `reserve_invoice_scan` و`release_invoice_scan`
(لـ service_role فقط).

## 3. أسرار Supabase Edge Function

| المتغير | القيمة | ملاحظة |
|---|---|---|
| `ANTHROPIC_API_KEY` | المفتاح من الخطوة 1 | إلزامي |
| `SCAN_ENABLED` | `true` | إلزامي |
| `SCAN_MONTHLY_PAGES` | `3` افتراضيًا | صفحات كل منشأة في الشهر (بتوقيت الرياض) |
| `SCAN_DAILY_CAP` | `200` افتراضيًا | سقف يومي لكل المنشآت لحماية التكلفة |
| `SCAN_MODEL` | `claude-sonnet-5-5` افتراضيًا | يمكن تجربة `claude-haiku-5-5` لتكلفة أقل |

```bash
supabase secrets set ANTHROPIC_API_KEY=... SCAN_ENABLED=true
```

ثم أعد نشر الدالة `api`.

## 4. الويب

اضبط `NEXT_PUBLIC_SCAN_ENABLED=true` في متغيرات بناء Cloudflare Pages وأعد البناء.

## الحماية والتكلفة

- **حصة لكل منشأة:** تُحجز صفحة بعملية ذرّية قبل استدعاء النموذج. تُعاد الصفحة إذا
  فشل المزوّد أو امتلأ السقف اليومي، ولا تُعاد إذا كانت الصورة غير مقروءة (المزوّد
  تقاضى ثمنها، والإرجاع يسمح باستنزاف السقف بصور عشوائية).
- **سقف يومي عام** عبر `consume_external_usage_budget` بالمفتاح `invoice-scan`.
- **حد معدل:** 5 محاولات في الدقيقة لكل حساب.
- **الصورة:** JPEG أو PNG أو WebP حتى 4.5 ميغابايت؛ الويب يصغّرها إلى 2000 بكسل
  ويعيد ترميزها (فتُحذف بيانات EXIF مثل الموقع).
- **ما يُرسل للمزوّد:** الصورة وأسماء مواد المنشأة ووحداتها ومعرّفاتها فقط، بلا
  بيانات الحساب. نص الصورة يُعامل كبيانات لا تعليمات، والناتج يُنقّى في الخادم:
  وحدات من القائمة فقط، وأرقام موجبة، ومعرّف مادة لا يُقبل إلا إن كان من مواد
  المنشأة نفسها، وتاريخ ميلادي معقول.
- **الخصوصية:** إشعار الخصوصية يذكر Anthropic في قسم «قراءة فواتير الشراء».

## الأخطاء التي تراها الواجهة

| الرمز | الحالة | المعنى |
|---|---|---|
| — | 501 | المسح غير مفعّل في الخادم |
| `SCAN_IMAGE_INVALID` | 400 / 413 | صيغة أو حجم صورة غير مقبول |
| `SCAN_QUOTA_EXCEEDED` | 429 | انتهت صفحات الشهر |
| `RATE_LIMITED` | 429 | محاولات كثيرة في دقيقة |
| `SCAN_UNREADABLE` | 422 | لم تُستخرج أصناف من الصورة |
| `SCAN_FAILED` | 502 | فشل المزوّد أو انتهت المهلة (45 ثانية) |
| — | 503 | السقف اليومي العام ممتلئ |
