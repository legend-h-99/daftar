# PM Skills Workspace

هذا المجلد يجمع مهارات إدارة المنتج التي طلبتها في مساحة عمل واحدة قابلة للاستخدام.

## الحزم المستخدمة

- `pm-product-strategy`: استراتيجية المنتج، الرؤية، القيمة، النمو، والتموضع.
- `pm-product-discovery`: اكتشاف الفرص، الافتراضات، المقابلات، والتجارب.
- `pm-market-research`: حجم السوق، الشرائح، المنافسين، الرحلة، والانطباع.
- `pm-data-analytics`: SQL، التحليل، التجارب، cohort analysis، ومؤشرات المنتج.
- `pm-marketing-growth`: North Star Metric، التموضع، أفكار النمو، وأسماء المنتجات.
- `pm-go-to-market`: استراتيجية الإطلاق، ICP، beachhead segment، battlecards، وقنوات النمو.
- `pm-execution`: PRD، OKRs، roadmap، user stories، sprint، pre-mortem، release notes.
- `pm-ai-shipping`: وثائق الشحن، مطابقة المقصود مع المنفذ، الاختبارات، والتدقيق.
- `pm-toolkit`: سياسات الخصوصية، NDA، التدقيق اللغوي، ومراجعة السير الذاتية.
