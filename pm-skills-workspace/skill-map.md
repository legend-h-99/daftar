# Skill Map

## استخدم هذا عندما تقول لي ماذا تريد

| الطلب | المهارة المناسبة | الناتج المتوقع |
|---|---|---|
| عندي فكرة منتج وأريد استراتيجية | `pm-product-strategy` | Strategy Canvas ورؤية وقيمة وتميز |
| لا أعرف ماذا أبني أولًا | `pm-product-discovery` | Opportunity Solution Tree وتجارب |
| أريد معرفة حجم السوق | `pm-market-research` | TAM / SAM / SOM وافتراضات |
| أريد قياس النجاح | `pm-marketing-growth` + `pm-data-analytics` | North Star ومؤشرات وأسئلة SQL |
| أريد خطة إطلاق | `pm-go-to-market` | GTM plan وICP وقنوات ورسائل |
| أريد تحويل الفكرة إلى تنفيذ | `pm-execution` | PRD وRoadmap وUser Stories |
| أريد تجهيز الشحن والمراجعة | `pm-ai-shipping` | وثائق system review وقائمة اختبارات |
| أحتاج سياسة خصوصية أو NDA | `pm-toolkit` | مسودة أولية تحتاج مراجعة قانونية |

## أوامر طبيعية يمكنك استخدامها

- "استخدم strategy على هذه الفكرة: ..."
- "ابن لي Opportunity Solution Tree."
- "حوّل هذه الميزات إلى outcome roadmap."
- "اكتب PRD مختصر."
- "حدد North Star Metric."
- "جهز GTM plan."
- "اعمل shipping checklist لهذا التطبيق."
- "قارن intended vs implemented."
