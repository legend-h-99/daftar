## Remaining Issues

### P2 — Medium priority

**P2-1: No optimistic / stale-while-revalidate pattern**  
When the user navigates back to dashboard after visiting invoices, data re-fetches from scratch (spinner reappears). The prior month's data could be preserved in a simple ref while the new fetch resolves.  
*Fix:* Cache last result in a `useRef` and render it immediately while the new fetch is in flight.

**P2-2: Low-stock alert truncates at 3 items with no clear affordance to see the rest**  
«و3 أصناف أخرى» is shown as plain text, not a link. Users may not realize tapping the whole card navigates to /inventory.  
*Fix:* Add a `← عرض الكل` inline link or underline-style hint within the amber box.

### P3 — Low priority / polish

**P3-1: Month label too subdued**  
`text-sm text-gray-500` with `min-w-[100px]` is readable but gives the month equal weight to secondary metadata. The month is the primary context switch; bump to `text-sm font-semibold text-gray-700`.

**P3-2: Unpaid invoice list has no empty divider / spacing from low-stock alert**  
When both `lowStock` and `unpaidInvoices` are populated, the amber box and the section header are visually adjacent with only the flex-col gap-4. A slightly larger gap (`gap-6`) between the two sections would improve scannability.

**P3-3: «لي عند الزباين» section header missing `aria-level`**  
`<h2>` is correct but lives inside an `aria-live` region. Screen readers may re-announce it on every month change. Wrap the static header outside the live region and only wrap the dynamic invoice list inside `aria-live`.
