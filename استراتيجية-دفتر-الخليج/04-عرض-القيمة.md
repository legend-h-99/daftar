# عرض القيمة — Value Proposition

*الأفراد والأعمال الصغيرة جدًا · السعودية والخليج · نسخة مفصّلة*

## ١. جملة القيمة الفريدة (UVP)
> **«لفردٍ أو عملٍ صغير جدًا يبيع من البيت عبر واتساب ولا يعرف كم ربح — دفتر تطبيق عربي يحسب ربحك تلقائيًا ويذكّرك بمن لم يدفع. خلافًا لبرامج المحاسبة، دفتر مبني لك، لا للمحاسبين.»**

**قالب UVP (For–Who–The–That–Unlike–Our):**
- **For:** فرد/عمل صغير جدًا يبيع من البيت.
- **Who:** لا يعرف ربحه الحقيقي ويعيش في واتساب.
- **The (دفتر):** تطبيق حسابات عربي جوال-أولًا.
- **That:** يحسب الربح تلقائيًا ويتتبّع الديون بلغة السوق.
- **Unlike:** برامج المحاسبة (قيود/Wafeq) والورقة/Excel.
- **Our:** مبني لهذه الشريحة تحديدًا، بوصفات تحسب التكلفة، وتوطين محلي عميق.

## ٢. Value Proposition Canvas — عام

### ملف العميل (Customer Profile)
| الوظائف (Jobs) | الآلام (Pains) | المكاسب (Gains) |
|---|---|---|
| «أعرف إذا مشروعي يستاهل» | لا يعرف ربحه (ينسى التكاليف) | رقم صافٍ واحد للربح الشهري |
| «أتابع مين مديون لي» | زبائن لا يدفعون وهو ناسٍ | «لي عند» بنقرة + تذكير |
| «أسعّر منتجي صح» | تسعير بالحدس | تكلفة الإنتاج من الوصفة |
| «أبدو محترفًا» | لا فاتورة رسمية | فاتورة PDF عربية بواتساب |
| «أشتغل بسرعة وأنا مشغول» | أدوات ثقيلة ومعقّدة | ٣ نقرات، عربي، من الجوال |
| «ما أحرج نفسي بالمطالبة» | صعوبة المطالبة بالدين | تذكير بنبرة لطيفة جاهزة |

### خريطة القيمة (Value Map)
| المنتجات/الخدمات | مسكّنات الألم | صانعات المكسب |
|---|---|---|
| فوترة + مشاركة واتساب | يلغي الورقة والتخمين | تقرير ربح فوري «١٠ ثوانٍ» |
| وصفات تحسب التكلفة | يزيل خطأ التسعير | «لي عند» + تذكير تلقائي |
| تقارير ربح ومصاريف | يكشف الخسارة مبكرًا | لغة السوق لا المحاسبة |
| «لي عند» + تذكير | يوقف تسرّب الإيراد | RTL أصيل + تجربة جوال |
| توطين (عملة/لهجة) | يزيل الغربة عن الأدوات العالمية | «مبني لسوقك» |

**درجة الملاءمة (Fit):** كل ألم رئيسي ↔ مسكّن مقابل، وكل مكسب ↔ صانع مقابل → ملاءمة قوية (Problem-Solution Fit مرتفع).

## ٣. VPC حسب الشريحة (تمايز)

### أ. الأسرة المنتجة (طعام/حرف)
- **أهم Job:** «أعرف ربحي وأسعّر صح» · **أهم مسكّن:** الوصفات + تقرير الربح.
- **رسالة:** «اعرفي ربحك بعد التكاليف — مو بس مبيعاتك.»

### ج. المستقل / الفرد (خدمات)
- **أهم Job:** «فواتير احترافية وتحصيل» · **أهم مسكّن:** وضع خدمة بلا مخزون + «لي عند».
- **رسالة:** «فواتيرك وتحصيلك في مكان واحد — بلا تعقيد.»

### د. العمل المنزلي الأكبر قليلًا
- **أهم Job:** «تحكّم بالمخزون والأرباح» · **أهم مسكّن:** المخزون + التقارير.
- **رسالة:** «تحكّمي بمخزونك واعرفي صافي ربحك شهريًا.»

## ٤. سلّم القيمة (قبل / بعد)
| | قبل دفتر | بعد دفتر |
|---|---|---|
| معرفة الربح | «ما أدري كسبت ولا خسرت» | «ربحي هذا الشهر ٧٤٠ ريال» في ١٠ ثوانٍ |
| الديون | في الدماغ/ورقة ضائعة | قائمة واضحة + تذكير |
| التسعير | تقليد المحيط | مبني على التكلفة الحقيقية |
| الصورة | رسالة واتساب عادية | فاتورة باسم المشروع |
| الذروة (رمضان) | فوضى وطلبات ضائعة | تتبّع منظّم |

## ٥. ملاءمة الرسالة للسوق (Message–Market Fit)
| الشريحة | Hook | القناة |
|---|---|---|
| طعام | «شوفي ربحك في ١٠ ثواني» | واتساب + بنك التنمية |
| حرف | «سعّري صح وابدي محترفة» | إنستغرام مؤثرين |
| أفراد | «فواتير وتحصيل بلا تعقيد» | منصات العمل الحر |
| خليج | «حساباتك، بلغتك وعملتك» | إعلانات محلية بلهجة |

## ٦. معالجة الاعتراضات (Objection Handling)
| الاعتراض | الرد |
|---|---|
| «ما أحتاج محاسبة» | «مو محاسبة — دفتر يقول لك كم ربحت، بس.» |
| «التطبيقات معقّدة» | «٣ نقرات لأول فاتورة، جرّب.» |
| «غالي» | «مجاني للبداية، وأقل من فاتورة قهوة شهريًا.» |
| «بياناتي؟» | «خصوصيتك محفوظة (PDPL)، بياناتك لك.» |
| «أنا أستخدم الورقة» | «الورقة تُنسى — دفتر يحسب ويذكّر.» |

## ٧. أدلّة الإثبات (Proof Points) — تُبنى مع النمو
- قصص مستخدمات: «اكتشفت أني كنت أبيع بخسارة».
- بيانات مجمّعة: متوسط الوقت لأول فاتورة، نسبة من عرف ربحه.
- شهادة شريك (بنك التنمية) بعد الـpilot.

## ٨. رسائل تسويقية (Hooks جاهزة)
«شوف ربحك في ١٠ ثواني — مو بس مبيعاتك.» · «مين مديون لك؟ دفتر يذكّرك.» · «حساباتك، بلغتك.» · «مبني لمن يبيع من البيت — مو للمحاسبين.» · «من واتساب لدفتر في ثانيتين.»
