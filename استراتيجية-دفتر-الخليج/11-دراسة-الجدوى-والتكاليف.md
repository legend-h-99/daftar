# دراسة الجدوى والتكاليف — دفتر

*لمؤسّس فرد يبدأ بأقل تكلفة ممكنة (Bootstrapping) · السعودية · نسخة مفصّلة*

> ⚠️ الأرقام تقديرية بريالات ٢٠٢٦ وتحتاج تحققًا من أسعار المزوّدين الحالية. الفلسفة: **صفر تكلفة ثابتة قدر الإمكان، وادفع فقط مع النمو.**

---

## ١. مبادئ Bootstrapping (الأصل الحاكم)
1. **الطبقات المجانية أولًا** — استضافة وقاعدة بيانات ومراقبة على free tiers حتى تصطدم بحدودها فعلًا.
2. **أجّل كل تكلفة متغيّرة** — لا SMS مدفوع قبل أول مستخدم حقيقي؛ استخدم WhatsApp/بديل رخيص.
3. **المؤسّس يفعل كل شيء** — تطوير، دعم (واتساب)، تسويق — لا توظيف قبل الإيراد.
4. **وقتك هو رأس مالك** — أكبر «تكلفة» هي وقتك؛ احسبه لكنه غير نقدي في البداية.
5. **لا تُنفق على ما يمكن تأجيله** — العلامة/الموقع/الإعلانات تأتي بعد إثبات القيمة.

---

## ٢. الجدوى بأربعة محاور

### أ. الجدوى التقنية ✅ عالية
- **الـMVP مبني فعلًا** (ويب Next.js + API NestJS/Prisma/Postgres + موبايل Expo). لا حاجة لبناء من الصفر.
- Stack خفيف: بلا Redis/طوابير/puppeteer؛ الفواتير PDF محليًا بـ`pdfkit` (بلا تكلفة خارجية).
- قابل للإدارة من فرد واحد. **الخطر التقني الأساسي:** ربط مزوّد SMS للإنتاج (حاليًا وهمي).

### ب. الجدوى المالية ✅ عالية (تعادل مبكر جدًا)
- التكلفة الثابتة الشهرية الدنيا ضئيلة (§٤). **التعادل يتحقق بـ٣–٦ مشتركين مدفوعين فقط** (§٥).

### ج. الجدوى التشغيلية ✅ متوسطة–عالية
- خدمة ذاتية (Onboarding جوال) + دعم واتساب من المؤسّس. الخطر: **الدعم يستهلك وقت المؤسّس** مع النمو → تُخفّفه القوالب والأسئلة الشائعة والمحتوى التعليمي.

### د. الجدوى القانونية ✅ ممكنة بحذر
- **وثيقة عمل حر** للمؤسّس (منصة العمل الحر) — رخيصة/مجانية، كافية للبداية دون سجل تجاري.
- **PDPL:** التزام خصوصية إلزامي (تُعالَج في الخطة التقنية).
- **لا ادعاء امتثال ZATCA/فوترة إلكترونية** قبل التحقق الرسمي — يبقيك خارج التزامات مكلفة مبكرًا.

## ٤. التكاليف الشهرية المتكرّرة (السيناريو الأدنى) ⚠️
| البند | الخيار الأرخص | التكلفة/شهر | متى تدفع |
|---|---|---|---|
| استضافة الويب | Vercel Hobby (مجاني) / Cloudflare Pages | **٠** | فورًا |
| قاعدة البيانات | Supabase / Neon (طبقة مجانية) | **٠** | حتى ~٥٠٠MB |
| استضافة الـAPI | VPS صغير (Hetzner) أو Railway | **~١٨–٢٠ ريال** | فورًا |
| التحقق (OTP) | WhatsApp Cloud API (أول ١٠٠٠ محادثة مجانًا) أو SMS رخيص | **٠ → ~١٥ ريال** | مع أول مستخدمين |
| نطاق (مُوزّع) | ~٥٠/سنة | **~٤ ريال** | سنوي |
| مراقبة/أخطاء | Sentry + PostHog (مجاني) | **٠** | فورًا |
| **الإجمالي الشهري الأدنى** | | **~٢٥–٤٠ ريال** ⚠️ | |
| + إطفاء Apple سنويًا | ~٣٧٠/١٢ | ~٣١ ريال | عند iOS |

**الخلاصة:** يمكن تشغيل دفتر فعليًا بـ **~٢٥–٤٠ ريال شهريًا** في البداية (بلا iOS)، و~٦٠–٧٠ ريال شاملًا iOS مُطفأً.

## ٥. تحليل التعادل (Break-even)
| السيناريو | التكلفة الشهرية ⚠️ | ARPU | مشتركون للتعادل |
|---|---|---|---|
| أدنى (ويب+أندرويد) | ~٤٠ ريال | ٢٩ ريال | **~٢** |
| متوسط (+iOS مُطفأ +SMS) | ~٩٠ ريال | ٣٥ ريال | **~٣** |
| مع نمو (SMS أعلى +Vercel Pro) | ~٣٠٠ ريال | ٣٥ ريال | **~٩** |

> **التعادل يتحقق بحفنة مشتركين** — الجدوى المالية ليست العائق؛ العائق **الاستحواذ والاحتفاظ**.

## ٦. الميزانية الزمنية للمؤسّس (رأس المال الحقيقي)
| النشاط | ساعات/أسبوع (تقديري) |
|---|---|
| تطوير وصيانة | ١٥–٢٥ |
| دعم عملاء (واتساب) | ٥–١٠ |
| تسويق/محتوى/شراكات | ٥–١٠ |
| **الإجمالي** | ~٢٥–٤٥ ساعة |

**تنبيه:** أكبر خطر ليس المال بل **إرهاق المؤسّس**. خفّفه بالأتمتة (قوالب، أسئلة شائعة، Onboarding ذاتي) وبتأجيل ما لا يثبت قيمته.

## ٧. مسار خفض/تأجيل التكاليف
1. **ابدأ بالويب + أندرويد** فقط (أجّل Apple ٣٧٠ ريال حتى الطلب).
2. **WhatsApp OTP** بدل SMS (يوفّر تكلفة الرسائل).
3. **قاعدة بيانات مجانية** حتى تتجاوز حدودها فعلًا.
4. **لا إعلانات مدفوعة** قبل إثبات الاحتفاظ (D30).
5. **الشراكة (بنك التنمية)** كقناة استحواذ شبه مجانية بدل الإعلانات.

## ٨. تكلفة إضافة iOS (iPhone) — تفصيل
> **الخلاصة أولًا:** iOS لا يضيف منتجًا بل **قناة نشر**؛ تطبيقك Expo/React Native يعمل على iOS أصلًا. الزيادة النقدية الوحيدة الجوهرية = **رسوم Apple ~٣٧٠ ريال/سنة (~٣١ ريال/شهر مُطفأ)**؛ الباقي وقت لا مال.

### أ. الزيادة النقدية
| البند | التكلفة ⚠️ | النوع | مجاني؟ |
|---|---|---|---|
| **Apple Developer Program** | ~٣٧٠ ريال/سنة ($99) | متكرر سنوي | ❌ إلزامي |
| بناء iOS (EAS Cloud) | ٠ | الطبقة المجانية تكفي إطلاقًا | ✅ |
| الاختبار (TestFlight + محاكي جهازك) | ٠ | — | ✅ |
| الـbackend / قاعدة البيانات | ٠ إضافي | نفسها تخدم الويب+أندرويد+iOS | ✅ |
| أصول App Store (لقطات/وصف) | ٠ | من الشاشات المُعاد تصميمها | ✅ |
| **إجمالي الزيادة** | **~٣٧٠ ريال/سنة فقط** | | |

### ب. الأثر على الأرقام
| المؤشر | ويب + أندرويد | + iOS |
|---|---|---|
| التكلفة الشهرية ⚠️ | ~٤٠ ريال | **~٧٠ ريال** |
| تكلفة الإطلاق لمرة واحدة | ~١٦٥ ريال | ~١٦٥ ريال (رسوم Apple **سنوية** لا إطلاق) |
| مشتركون للتعادل | ~٢–٣ | **~٣–٤** |

### ج. التكلفة الحقيقية = وقتك (~أسبوع عمل)
- **توطين iOS:** safe areas · نصوص أذونات `Info.plist` · خطوط Tajawal · أيقونة/سبلاش.
- **أصول App Store:** لقطات + وصف عربي + سياسة خصوصية (جاهزة من خطة P1).
- **مراجعة Apple:** أصرم من Google Play — توقّع دورة أو دورتين مراجعة (وقت لا مال).

### د. متى تضيفه (التوصية)
أجّل iOS إلى **P2**: أطلق ويب+أندرويد أولًا بـ~٤٠ ريال/شهر، وأضف iPhone **بعد إشارة أولى** (أول مستخدمين/احتفاظ D30) — فتدفع الـ٣٧٠ ريال **بعد** تأكيد الطلب لا قبله. مبرّر إضافي: شريحة الأسر المنتجة في السعودية تميل لاستخدام آيفون، لذا iOS مهم — لكن **بعد** إثبات القيمة على أرخص قناتين أولًا.
