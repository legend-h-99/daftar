# الخطة التقنية — دفتر

*لمؤسّس فرد · نشر بأقل تكلفة · إنتاج جاهز تدريجيًا · نسخة مفصّلة*

## ١. المعمارية الحالية (كما هي مبنية)
```
Monorepo (pnpm workspaces)
├── apps/web     → Next.js 15 (App Router, React 19) · Tailwind · Base UI/shadcn · RTL/Tajawal
├── apps/api     → NestJS 10 · Prisma 5 · PostgreSQL · JWT · Throttler · pdfkit (فواتير PDF عربية)
└── apps/mobile  → Expo (React Native 0.79) · expo-router · TanStack Query · Zustand · Tajawal
```
**نقاط قوة تقنية:** stack خفيف (بلا Redis/طوابير)، فواتير PDF محليًا (بلا خدمة خارجية)، تحديد معدّل مدمج (`@nestjs/throttler`)، JWT + قائمة إبطال (blacklist)، أساس أمني قائم (CSP، تحقّق أنواع الملفات، حدود استعلام).

## ٢. النشر بأقل تكلفة (Deployment Map)
| المكوّن | الخيار الأرخص | البديل عند النمو | التكلفة ⚠️ |
|---|---|---|---|
| **الويب** | Vercel Hobby / Cloudflare Pages | Vercel Pro ($20) | ٠ |
| **الـAPI (NestJS)** | VPS صغير (Hetzner CX22 ~€4.5) أو Railway | VPS أكبر / حاويات | ~١٨–٢٠ ريال/شهر |

**توصية البداية:** الويب على **Vercel Hobby** + الـAPI على **VPS واحد ~٢٠ ريال** (يشغّل NestJS + Postgres معًا في البداية، أو Postgres على Supabase مجاني) — يبقيك تحت ~٤٠ ريال/شهر.

## ٤. الأمان (خطة موجزة — مرجعية OWASP/PDPL)
- ✅ **موجود:** JWT + إبطال · تحديد معدّل على OTP (٥/٦٠ث) والمصادقة · CSP · تحقّق أنواع الملفات · حدود استعلام.
- 🔜 **يُضاف:** تخزين OTP مُجزّأ (hashed) بانتهاء قصير · تشفير الحقول الحسّاسة عند اللزوم · تدوير أسرار · سجلّ تدقيق أساسي · نسخ احتياطي مشفّر · مراجعة تبعيات دورية (`pnpm audit`).
- **PDPL:** موافقة · حق الوصول/الحذف · تقليل جمع البيانات · تحديد مكان الاستضافة (يُفضّل داخل المنطقة عند التوسّع الرسمي).

## ٥. مسار التوسّع (متى تُنفق أكثر)
| العتبة | الإشارة | الترقية |
|---|---|---|
| ~٥٠٠MB قاعدة | امتلاء free tier | Supabase Pro / Postgres على VPS |
| ~١٠٠٠ محادثة واتساب/شهر | تجاوز المجاني | باقة WhatsApp مدفوعة أو SMS |
| زمن استجابة الـAPI يرتفع | حمل | VPS أكبر / فصل Postgres / كاش خفيف |
| بناء موبايل متكرر | حدود EAS | باقة EAS مدفوعة |
| فرق عمل | توظيف | بيئات staging + CI أنضج |

**قاعدة:** لا تُرقّي استباقيًا — رقِّ **عند** الاصطدام بالحدّ، مدفوعًا بالإيراد.

## ٦. التوطين الخليجي (تقنيًا)
- **العملة:** حقل عملة على مستوى النشاط + تنسيق أرقام لكل سوق (موجود أساس RTL/Tajawal).
- **اللهجة:** طبقة نصوص (i18n) قابلة للتبديل — الرسائل والتذكيرات بلهجة السوق.
- **الدفع/OTP المحلي:** مزوّدون محليون لكل دولة خلف نفس الواجهة المجرّدة.
- **الاستضافة:** يُفضّل إقليم قريب (الخليج/أوروبا) لتقليل الكمون والتوافق التنظيمي.

## ٨. قرارات تقنية موصى بها (لمؤسّس فرد)
1. **ابدأ بمنصّة تُدار ذاتيًا قدر الإمكان** (Vercel + Supabase) لتقليل عبء DevOps.
2. **جرّد المزوّدين خلف واجهات** (SMS، تخزين، دفع) لسهولة التبديل والتوطين.
3. **أتمتة مبكرة رخيصة** (GitHub Actions مجاني) توفّر وقتك — أثمن مورد.
4. **راقب من اليوم الأول** (Sentry+PostHog مجاني) — لا تطر أعمى.
5. **لا تُحسّن قبل الأوان** — الـstack الحالي يكفي لآلاف المستخدمين قبل أي إعادة معمارية.

## ٩. أهم إجراء تقني عاجل
> **ربط مزوّد OTP حقيقي** (WhatsApp Cloud API أولًا لأنه الأرخص) — هو الفرق الوحيد الجوهري بين «MVP تجريبي» و«منتج قابل للإطلاق». كل شيء آخر يعمل.
